# AgriNex - Transporter & Driver Logistics Module 🚚

Dedicated mobile-first dispatch, turn-by-turn multi-stop navigation, and digital earnings console for commercial truck drivers, tempo operators, and idle delivery gig riders.

## 🚀 Key Features
1. **Driver Console & Vehicle Telematics**: Driver profile (*Karthik Raja*), Tata Ace EV battery status (84%), vehicle fitness, and route logs.
2. **Trip Dispatch Board (Accept / Decline)**: Real-time load broadcast from nearby farmers with payload weight, route, and upfront fare payout.
3. **Turn-by-Turn Multi-Stop Navigation**:
   - Multi-stop cluster collection: Stop ① Thindal (350kg) ➔ Stop ② Villarasampatti (450kg) ➔ Stop ③ Perundurai (400kg) ➔ Coimbatore Mandi Yard (1.2T Delivered).
   - Real Leaflet GPS road map with radar wave beacon, speed telematics, and distance remaining.
4. **Milestone Progress Stepper**: Tap-to-update status from *Assigned* to *Delivered*.
5. **⚡ Quick-Gig Downtime Mode**: "Go Online" toggle for Swiggy/Zomato riders to pick up farm produce orders during food delivery downtime.
6. **Digital POD Handover**: Verify buyer OTP, record arrival condition, and collect touchscreen signature.
7. **Earnings & Instant UPI Payout**: Itemized fare summary with 1-click instant bank withdrawal.
8. **SOS / Roadside Helpline**: 24/7 emergency breakdown assistance.
9. **100% Multilingual**: Native dynamic toggle between English, हिन्दी, and தமிழ்.

## 🏃 How to Run
Open `index.html` directly in any web browser or serve with:
`python -m http.server 3003`
