# AgriNex - Farmer & FPO Logistics Module 🌾

Dedicated logistics and cold-chain portal for smallholder farmers and Farmer Producer Organisations (FPOs).

## 🚀 Key Features
1. **Farmgate Pickup Booking**: Transparent freight calculator with instant ₹/kg & ₹/quintal pricing breakdowns.
2. **Shared On-Demand Logistics (Farmer Cluster)**: Combines 3 smallholder loads (350kg + 450kg + 400kg = 1.2 Tonnes) into a single Tata Ace EV, saving 54% on freight (₹1,950 saved).
3. **Cold Storage Branch (Perishable Safeguard)**: Automated decision tree to reserve nearby cold storage (+21 days shelf-life) when mandi buyers are delayed, preventing distress sales.
4. **Quick-Gig Downtime Fleet**: Book nearby idle Swiggy/Zomato cargo scooters and vans at 35%–50% discounts for urgent micro-deliveries.
5. **Google Maps / Swiggy-Style Live GPS Tracking**: Real Leaflet road map with multi-stop waypoints, radar pulse animation, and telematics HUD (Speed, Distance, ETA).
6. **Digital Proof of Delivery & Driver Rating**: 4-digit OTP handover and 5-star driver review system.
7. **100% Multilingual**: Native dynamic toggle between English, हिन्दी, and தமிழ்.

## 🏃 How to Run
Open `index.html` directly in any web browser or serve with:
`python -m http.server 3001`
