# AgriNex - Agricultural Logistics Ecosystem 🚚🌾

Complete stakeholder-tailored agricultural supply chain & cold-chain management system.

## 📁 Repository Structure
This repository contains 4 specialized, standalone logistics modules:

1. **🌾 [Farmer Logistics Module](./farmer%20log%20mod/) (`farmer log mod`)**:
   - Farmgate pickup booking with instant ₹/kg & ₹/quintal freight pricing.
   - Shared On-Demand Logistics & Farmer Cluster (1.2 Tonne pooled load saving 54% cost).
   - Cold Storage Branch decision tree (+21 days shelf-life reservation to prevent distress selling).
   - Quick-Gig downtime fleet (Swiggy/Zomato cargo scooters/vans at 35%–50% discount).
   - Live Leaflet GPS tracking with radar wave beacon & telematics HUD.
   - Digital POD receiver OTP verification & 5-star driver rating.

2. **🏭 [Buyer Logistics Module](./buyer%20log%20mod/) (`buyer log mod`)**:
   - Inbound shipments radar with real-time truck telematics and arrival ETAs.
   - Gate entry, weighbridge tare/gross logs, and unloading dock allocation (Bays #1 to #6).
   - Produce arrival quality inspection (Grade A / B / Spillage / Rejected).
   - Digital Proof of Delivery (POD) terminal with touchscreen signature pad & automated escrow release.
   - Direct cold storage inward transfer tracking.
   - Automated tax invoices and goods receipt notes (GRN).

3. **🚚 [Transporter / Driver Module](./transporter%20log%20mod/) (`transporter log mod`)**:
   - Driver console with vehicle health & EV battery monitoring.
   - Real-time trip dispatch board (Accept / Decline incoming farmer pickup requests).
   - Turn-by-turn multi-stop cluster route navigator (Stop ① ➔ Stop ② ➔ Stop ③ ➔ Mandi).
   - Tap-to-update milestone progress stepper.
   - ⚡ Swiggy/Zomato downtime mode toggle (Online/Offline for farm micro-runs).
   - Digital POD handover terminal.
   - Driver wallet with instant UPI payout transfer.
   - 24/7 Roadside emergency SOS breakdown assistance.

4. **🛡️ [Admin Supervision Module](./admin%20log%20mod/) (`admin log mod`)**:
   - Command Tower KPI dashboard (active fleet, tonnage in transit, on-time SLA 98.4%).
   - Fleet & driver KYC verification hub (RC book, commercial permit, driver license audit).
   - Regional corridor telematics and live multi-vehicle map across NH 544.
   - Dispute & incident triage center (breakdowns, delay grievances, backup vehicle dispatch).
   - Freight tariff caps & Operation Greens 50% perishable subsidy manager.
