# AgriNex - Admin Supervision & Command Tower Logistics Module 🛡️

Dedicated oversight, fleet KYC compliance, telematics command center, and dispute resolution portal for Supply Chain Directors and Agricultural Logistics Administrators.

## 🚀 Key Features
1. **Command Tower KPIs**: Real-time fleet metrics, active tonnage in transit (42.6T), on-time fulfillment rate (98.4%), and average ₹/kg freight cost.
2. **Fleet & Driver KYC Verification Desk**: Inspect transporter vehicle registration, commercial permits, reefer calibration, and driver license KYC with 1-click approval/suspension.
3. **Corridor Telematics & Live Map**: Regional interactive Leaflet map monitoring all active trucks across South India agricultural trade corridors (NH 544, Erode, Tiruppur, Coimbatore) with speed and temperature datalogger alerts.
4. **Dispute & Grievance Resolution Center**: Triage vehicle breakdowns, transit spoilage, and delay grievances with emergency backup vehicle dispatch tools.
5. **Freight Tariff & Government Subsidy Manager**: Configure regional base fares, per-km rates, and manage Operation Greens / PM-Kisan 50% freight subsidy allotments.
6. **Cold Chain Audit & Capacity Reserves**: Monitor accredited cold rooms (WDRA compliance, temperature audit logs).
7. **100% Multilingual**: Native dynamic toggle between English, हिन्दी, and தமிழ்.

## 🏃 How to Run
Open `index.html` directly in any web browser or serve with:
`python -m http.server 3004`
