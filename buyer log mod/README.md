# AgriNex - Buyer & Processing Plant Logistics Module 🏭

Dedicated inbound receiving, gate inspection, and digital proof-of-delivery (POD) portal for Mandi Commission Agents, Food Processors, and Retail Chains.

## 🚀 Key Features
1. **Inbound Shipments Radar**: Real-time telematics of all trucks approaching the facility with dynamic ETA, cargo temperature, and driver contact.
2. **Gate Entry & Quality Inspection**: Weighbridge tare/gross logs, dock bay allocation (Bay #1 to #6), and produce quality grading (Fresh / Minor Loss / Rejected).
3. **Digital Proof of Delivery (POD) Terminal**:
   - OTP code verification with the delivery driver.
   - HTML5 Interactive Touchscreen Signature Pad for receiving managers.
   - Instant Escrow Payment Release directly to farmer & transporter upon sign-off.
4. **Cold Storage Inward Transfers**: Real-time tracking of chilled shipments dispatched directly from accredited cold storage facilities.
5. **Itemized Receiving Invoices**: Automated tax slips and goods receipt notes (GRN).
6. **Dispute & Damage Escalation**: 1-click filing for transit spillage, broken crates, or delayed arrivals.
7. **100% Multilingual**: Native dynamic toggle between English, हिन्दी, and தமிழ்.

## 🏃 How to Run
Open `index.html` directly in any web browser or serve with:
`python -m http.server 3002`
